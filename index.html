Formation

Mes Compétences BUT R&T

Le BUT Réseaux & Télécoms s'articule autour de 3 compétences transversales : Administrer, Connecter et Programmer, approfondies chaque année.

🛡️
Administrer

Configurer et gérer des équipements réseau dans un environnement simple. Mise en place des services de base (DHCP, DNS, VLAN) et maintenance d'infrastructures locales.

Cisco IOS Linux DHCP / DNS VLAN SSH
🌐
Connecter

Comprendre et mettre en œuvre les protocoles de communication fondamentaux. Câblage, modèle OSI, adressage IP, routage statique et bases des protocoles TCP/IP.

TCP/IP IPv4 / IPv6 Routage statique Fibre / Cuivre Wireshark
💻
Programmer

Développer des scripts et des petites applications pour automatiser des tâches réseau. Introduction à la programmation et aux outils de développement.

Python Bash HTML / CSS Git Scripts réseau
🚀

En 2ème année, les trois compétences sont approfondies dans des contextes plus complexes : environnements multi-sites, sécurité renforcée, automatisation avancée et projets transversaux en autonomie.

🔒
Administrer – Niveau 2

Gestion d'infrastructures complexes et multi-sites. Administration avancée de serveurs, virtualisation, supervision réseau, haute disponibilité et introduction à la cybersécurité.

VPN / IPSec Firewall Proxmox / VMware Nagios / Zabbix Active Directory OSPF / BGP
📡
Connecter – Niveau 2

Interconnexion de réseaux hétérogènes, technologies WAN, sans fil avancé (Wi-Fi, 4G/5G). Qualité de service, ToIP, et découverte des architectures SDN et cloud networking.

MPLS / SD-WAN Wi-Fi 802.11 QoS VoIP / ToIP 5G Cloud (AWS/Azure)
⚙️
Programmer – Niveau 2

Automatisation d'infrastructure avec des outils professionnels, développement d'applications réseau, APIs REST et initiation au DevOps. Gestion de projets et travail collaboratif.

Ansible Python avancé API REST Docker Git / CI-CD SQL
